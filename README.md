# Healthcare-Patient-Analytics-Operational-Reporting-
Analyzed 5,000+ patient records using Python and SQL to evaluate healthcare KPIs, treatment costs, length of stay, recovery, and readmission risk. Performed data validation and cleaning, then created IBM Cognos reports to visualize operational insights.
Healthcare Patient Analytics & Operational Reporting

Project Overview

This project analyzes healthcare data to identify patient and operational insights, including:

Patient visit volume
Treatment costs
Length of stay
Recovery scores
Readmission risk
Department and treatment-level KPIs
Data Quality & Cleaning
Checked for duplicate records
Performed completeness checks
Validated data types
Checked numerical values for errors
Removed duplicate records
Flagged unusual length-of-stay values for further investigation
Tools & Technologies
Python – Data cleaning and analysis
SQL – Data querying and KPI analysis
Key Outcomes
The project provides a structured and repeatable workflow for data validation, healthcare analytics, KPI generation, and operational reporting.
